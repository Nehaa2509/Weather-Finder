# Weather Finder 🌤️

Weather Finder is a web-based application built using Python Flask that allows users to search for real-time weather information of any city.

The application fetches live weather data from the OpenWeather API and displays temperature, humidity, and weather conditions in a simple and user-friendly interface.

## Live Demo
https://weather-finder--221210116040.replit.app

## Features
- Search weather by city name
- Displays temperature in Celsius
- Shows humidity and weather description
- Real-time data using OpenWeather API
- Deployed online using Replit

## Tech Stack
- Python
- Flask
- HTML / CSS
- OpenWeather API
- Replit (Deployment)

## How It Works
1. User enters a city name
2. Flask backend sends request to OpenWeather API
3. Weather data is fetched and processed
4. Results are displayed on the web page
